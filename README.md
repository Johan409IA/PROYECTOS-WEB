# **Estructura de Portafolio Básico en HTML**

Este proyecto consiste en la creación de la estructura fundamental para un sitio web de portafolio personal, utilizando exclusivamente **HTML**. El enfoque principal es establecer una base semántica, bien organizada y optimizada para SEO, que esté lista para ser estilizada con CSS en una fase posterior.

## 🏁 **Objetivos del Proyecto**

El desarrollo de este proyecto se centró en cumplir con los siguientes objetivos de aprendizaje y técnicos:

  - **Aprender a crear un sitio web de múltiples páginas:** Implementar una navegación funcional que conecte diferentes archivos HTML.
  - **Estructurar un sitio web de manera semántica:** Utilizar etiquetas HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<article>`, etc.) para dar significado y contexto al contenido, mejorando la accesibilidad y el SEO.
  - **Crear una base escalable:** Diseñar una estructura que permita añadir estilos con CSS de forma sencilla y eficiente en el futuro.
  - **Implementar metaetiquetas SEO:** Incluir metadatos esenciales en el `<head>` de cada página para mejorar el posicionamiento en motores de búsqueda.

## 📂 **Estructura de Archivos**

El sitio está compuesto por cuatro páginas principales, cada una con un propósito específico:

  - `layout.html`: La página de inicio, que presenta un resumen general del perfil profesional.
  - `projects.html`: Una página dedicada a mostrar la lista de proyectos realizados.
  - `articles.html`: Una sección para mostrar artículos, publicaciones o reseñas.
  - `contact.html`: Contiene un formulario de contacto funcional para que los visitantes puedan enviar mensajes.

## ✨ **Características Implementadas**

  - **HTML Semántico:** Se utilizaron etiquetas semánticas para definir claramente cada sección del sitio web.
  - **Navegación Coherente:** Cada página comparte la misma barra de navegación para una experiencia de usuario consistente.
  - **Optimización SEO Básica:** Cada página incluye etiquetas `<meta>` para `description`, `keywords` y `author`.
  - **Formulario de Contacto:** La página de contacto cuenta con un formulario HTML con campos para nombre, email y mensaje, listo para ser conectado a un backend o servicio de email.

## 🔮 **Pasos Futuros**

La estructura actual es solo el esqueleto. Los siguientes pasos para evolucionar este proyecto incluyen:

  - **Añadir Estilos con CSS:** Crear una hoja de estilos (`styles.css`) para dar vida al diseño visual del portafolio.
  - **Implementar Responsividad:** Asegurarse de que el sitio se vea bien en todos los dispositivos (móviles, tabletas y escritorios) utilizando *Media Queries*.
  - **Añadir Interactividad con JavaScript:** Incorporar funcionalidades dinámicas, como validaciones en el formulario de contacto o animaciones.
